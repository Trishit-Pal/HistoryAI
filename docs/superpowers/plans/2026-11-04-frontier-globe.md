# Frontier Globe, 2018–2026 Exhibits and Copy Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/globe` page showing where and how fast frontier-scale AI spread, add 10–14 confirmed 2018–2026 exhibits (with 2–3 replica artefacts), and tighten the site's copy.

**Architecture:**
- Globe data is computed at snapshot time from the Epoch AI zip the Atlas already ingests. `scripts/atlas-snapshot.ts` also writes `data/globe-snapshot.json`, using a pure `buildGlobe`.
- The page follows the Atlas pattern: a server page plus a client shell, with an R3F scene loaded via `next/dynamic` `ssr:false`.
- New exhibits follow the existing seed → validator → snapshot → `db:audit` path.

**Tech Stack:** Next.js 16 App Router (read `node_modules/next/dist/docs/` before using Next APIs), React 19, three 0.186, @react-three/fiber 9, @react-three/drei 10, gsap, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-04-frontier-globe-design.md`

## Global Constraints
- **Cutoff:** 2026-11-01, inclusive. Globe rows dated later are excluded.
- **Large-scale threshold:** training compute ≥ 10²³ FLOP, i.e. `logCompute >= 23`.
- **Labelling:** every Epoch figure is labelled "Epoch AI estimate" and links to Epoch's source for that model.
- **New exhibits:** they must pass the existing confirmed rule (`src/domain/confidence.ts`): `officialPrimary: true` and citations from at least 2 distinct hostnames. Every URL must be verified to resolve.
- **Exhibit count:** 10–14. Replica artefacts: 2–3, following `src/museum/artefacts.ts`.
- **Dependencies and assets:**
  - No new runtime dependencies, no glTF, no CDN assets, CSP (`next.config.ts`) unchanged.
  - Earth imagery is NASA Blue Marble (public domain), self-hosted, ≤ 2 MB.
- **Motion:** none when idle. Motion answers the user only, and everything snaps under `usePrefersReducedMotion`. Canvases use `frameloop="demand"`.
- **Files:** each under 200 lines.
- **Theme:** the night + gold tokens (`--bp-*`) and Cormorant headings.
- **Copy:** sentence case and plain verbs. Exhibit facts are never reworded in the copy pass.
- **Never** write to the production database. The owner runs `db:audit`.
- **Branch:** `feature/frontier-globe` from `origin/main`, with a PR into `main`. Merging deploys production.

## Review Focus
1. **A new country in Epoch's data with no centroid:** expect the build to fail loudly, not drop that country silently. Test in Task 1.
2. **A model listing several organisations or countries** (comma-separated): expect it counted once per country, and each lab counted once. Test in Task 1.
3. **Rows with no date, no compute, or a date after the cutoff:** expect them excluded from the counts, with no `NaN` in the totals. Test in Task 1.
4. **The slider at 2018,** before the first large-scale model: expect zero columns and the note line, not an empty or broken panel. Test in Task 5.
5. **A globe model whose Atlas link has no matching Atlas name:** expect the link omitted, not a dead hash. Test in Task 1 (`atlasName` is only set when the name is in the Atlas snapshot).

- Create: `data/globe-snapshot.json`, generated by `npm run atlas:snapshot` (it may also refresh `data/atlas-snapshot.json`; the Atlas tests must stay green)

**Interfaces:**
- Produces:
  ```ts
  type GlobeModel = { name: string; date: string; year: number; logCompute: number; organizations: string[]; link?: string; atlasName?: string };
  type GlobeCountry = { country: string; lat: number; lon: number; labs: string[]; models: GlobeModel[] }; // models sorted by date
  type GlobeRecord = GlobeModel & { multiplier: number | null }; // vs previous record; null for the first
  type GlobeSnapshot = { generatedAt: string; cutoff: "2026-11-01"; threshold: 23; countries: GlobeCountry[]; multinational: GlobeModel[]; records: GlobeRecord[] };
  function buildGlobe(rows: readonly Readonly<Record<string, string>>[], meta: { generatedAt: string; atlasNames: ReadonlySet<string> }): GlobeSnapshot // src/globe/build.ts
  const COUNTRY_CENTROIDS: Readonly<Record<string, [lat: number, lon: number]>> // src/globe/countries.ts, keys = Epoch's "Country (of organization)" spellings
  function statsAt(snapshot: GlobeSnapshot, year: number): { labs: number; countries: number; models: number; largest?: GlobeRecord } // src/globe/stats.ts, cumulative through the end of `year`
  ```
- Consumes: the Epoch CSV columns `Model`, `Publication date`, `Training compute (FLOP)`, `Organization`, `Country (of organization)`, and the link column, via the existing `firstHttpsUrl` and `toFractionalYear` in `src/atlas/build.ts`.

- [ ] **Step 1: Write the failing tests** in `src/globe/build.test.ts`, using small fixture rows:
  - `keeps only models at or above 1e23 FLOP dated on or before 2026-11-01`: a row with 9e22 is excluded, 1e23 is kept, and one dated 2026-11-02 is excluded.
  - `counts a multi-country model once per country and each lab once`: the row `Country = "United States of America,United Kingdom"` with `Organization = "Google DeepMind,Google"` gives both countries one model each, and `labs` has no duplicates.
  - `puts Multinational rows in multinational, not on the globe`.
  - `throws naming the country when a country has no centroid`: expect `/no centroid for "Atlantis"/`.
  - `records are the running maximum of compute across all rows from 2012 onward, with multipliers`: first `multiplier === null`, and later ones equal `10 ** (logCompute - prev.logCompute)`.
  - `sets atlasName only when the name is in atlasNames`.
